Liturgical Calendar Components JS: rite → calendar chain

Switch the rite below and watch the rest of the form react. No ApiClient request is made here: this example is only about how ApiOptions orchestrates the chain.

What to look for when you select Ambrosian:
  • The nation select disappears — the Ambrosian rite has no national tier.
  • All four Ambrosian dioceses appear at once. Under the Roman rite you have to pick a nation first, because the diocese select is linked to the nation select; the Ambrosian rite has no nation to filter by, so the whole list is shown.
  • Any calendar selection is cleared — a calendar id from one rite is never valid under another.
  • Epiphany, Ascension, Corpus Christi and Eternal High Priest are disabled — the Ambrosian Missal fixes them itself.
  • The year field will not accept anything before 1976, the first reformed Ambrosian Missal.
