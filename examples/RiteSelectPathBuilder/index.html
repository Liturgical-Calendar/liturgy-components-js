Liturgical Calendar Components JS: the rite as a path segment

A rite is a path segment, like a nation or a diocese — not a query parameter. Change the controls and watch the request path below rebuild.

Paths to try:
  • Roman, no calendar → /calendar/roman
  • Ambrosian, no calendar → /calendar/ambrosian
  • Ambrosian, Lugano → /calendar/ambrosian/diocese/lugano_ch
With a RiteSelect linked, the rite is spelled out even for Roman. Both forms are the same request: the API router accepts roman explicitly.
