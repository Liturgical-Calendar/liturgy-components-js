Scoped widgets

Two TodayViewers, each restricted with a scope option so it can only ever show the calendars a specific site would actually want — see "Calendar scope" in the project CLAUDE.md for the full model.

Diocese of Rome

scope: { diocese: 'romamo_it' } — one calendar, pinned by inference to the Roman rite and to Rome's own locales. No rite select, no calendar select, no locale input: there is only ever one choice for each, so none of the three has anything to offer.

Italian Bishops' Conference

scope: { nation: 'IT' } — the Italian national calendar under the Roman rite, or the bare Ambrosian calendar under Ambrosian (Italy has an Ambrosian diocese — Milan — even though Ambrosian has no national tier). The calendar select stays hidden either way: Italy resolves to exactly one calendar per rite. The locale input does not follow the same rule — it is derived from the CURRENT calendar's own locales, not from the calendar count — so switching the rite select to Ambrosian makes it appear: the bare Ambrosian calendar supports both it and la, while Italy's own national calendar under Roman supports only it.
