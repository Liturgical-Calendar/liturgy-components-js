Liturgical Calendar Components JS: an Ambrosian calendar

The full stack: RiteSelect → CalendarSelect → ApiOptions → ApiClient → WebCalendar. Switching the rite refetches and redraws the table below with real data.

Requires API v6 or the dev deployment. Rite support is detected from the /calendars metadata; against v5 the Ambrosian rite is refused with an explicit error rather than a bare 400.
Look for the Ambrosian differences. Advent begins six weeks before Christmas — 16 November 2026, not 30 November — and the liturgical colour is morello rather than viola. The table caption changes too, since WebCalendar takes the rite from the ApiClient it listens to.
